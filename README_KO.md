# STORYBORN v0.3 — 동화의 숲 통합 프로토타입

## 설치와 실행

1. Unity를 종료하고 `Storyborn_v0.3_Assets.zip`을 압축 해제합니다.
2. ZIP 안의 **Assets 내용**을 기존 Unity 프로젝트의 **Assets 안에** 복사합니다. 같은 Storyborn 파일은 덮어씁니다. `Assets/Assets`가 되지 않게 합칩니다.
3. Unity를 열고 컴파일이 끝나면 상단 **Storyborn → Play Prototype**을 누릅니다.
4. **Game 뷰를 클릭**해서 조작합니다. 16:9, 1280×720 권장입니다.

기준 버전 Unity 2022.3 LTS. 기존 Input Manager와 새 Input System을 모두 처리합니다. 이 ZIP은 프로젝트에 가져오는 소스·씬·도트이며 EXE나 설치된 다른 게임에 넣는 모드가 아닙니다. Packages/ProjectSettings 교체는 필요하지 않습니다.

## 조작

| 입력 | 기능 |
|---|---|
| A / D | 좌우 이동 |
| W / Space | 점프 |
| S | 발판 아래로 내려가기 |
| 좌클릭 | 기본 공격 |
| 우클릭 + WASD | 방향 무적 대시. 방향키가 없으면 바라보는 방향 |
| Q / E | 해당 슬롯의 장비 스킬 |
| F | 상호작용. 장비 근처에서 장비 확인, 출구에서 다음 경로, 그 외 전투 종료 후 정비 |
| B | 전투 종료 후 강화 화면, 시작 거점에서는 영구 성장 화면 |
| 1 / 2 | 장비 확인 화면에서 Q / E 슬롯과 교체 |
| B | 장비 확인 화면에서는 바닥 장비 파괴 |
| Esc | 화면 닫기 / 일시정지 |
| R | 사망·승리 후 시작점으로 회귀 |

## 이번 버전에서 플레이하는 흐름

최초 연구소 연습 → 시작 거점 → 숲 가장자리 → 과자집 구간 → 도깨비 정예 → 깊은 숲 → 정비 공터 → 야수 보스.

연구소 연습을 끝내면 이후 회차에서 생략됩니다. 사망하면 시작 거점부터 새 회차를 시작합니다. 숲에서는 발판 배치·일부 적 배치·보상 경로가 달라집니다. 현재는 최종 보스를 야수 한 종류로 구현했습니다.

전투를 끝내고 오른쪽 출구 근처에서 F를 누르면 다음 경로를 고릅니다. 일반 경로 두 개는 모두 전투를 포함하며 표식이 **다음 방의 보상**을 알려줍니다. 보상은 장비 / 골드 / 효과형 아이템입니다. 정비 공터는 야수 직전에 고정으로 등장합니다.

일반 적: 진저브레드, 광산 난쟁이, 독사과, 진저브레드를 생성하는 과자집. 과자집을 파괴하면 생성이 멈춥니다. 소환된 과자에는 추가 골드 보상이 없습니다. 독사과는 사망 위치에 짧은 독 장판을 남깁니다.

정예: 도깨비 악사 시험형. 느리고 넓은 지면 충격파를 점프·대시로 회피합니다.

야수: 돌진, 지면 충격파, 발톱 연타. 체력 절반 이하에서 속도가 빨라지고 발톱 연타가 2회에서 3회로 늘어납니다. 주황은 전조, 빨강은 활성, 보라는 회복 구간입니다.

## 레인보우와 장비

시작 장비 두 개는 조작 시험을 위해 매 회차 지급하는 임시 설정입니다. 최종 시작 장비 구성은 미정입니다. 획득 순간 아래 셋 중 하나가 정해지며 사용하는 동안 바뀌지 않습니다.

- 직선 사격: 전방으로 빠르게 발사.
- 화살비: 전방 일정 구역 위에서 화살이 떨어짐.
- 곡사 연사: 여러 화살이 곡선을 그리며 넓게 퍼짐.

Q/E 어느 슬롯에도 장착할 수 있습니다. 새 장비를 얻으면 그 자리에서 교체하거나 파괴합니다. 교체로 나온 기존 장비는 바닥의 선택 대상으로 남습니다. 예비 인벤토리는 없습니다. 장비를 남긴 채 **다음 방으로 이동하면 자동 파괴되어 파편을 받습니다.**

강화 화면에서는 Q/E 장비를 강화하거나 현재 장착한 장비를 파괴할 수 있습니다. 파편 강화는 +3까지 가능하며 피해량과 화살 수가 증가합니다. 사망·회귀하면 장비와 강화는 초기화됩니다. 골드로 체력을 회복할 수도 있습니다. 가격·피해·확률은 모두 테스트용 수치입니다.

효과형 아이템은 이번 버전에 ‘사과 부적’ 1종을 넣었습니다. 획득 시 이번 회차 최대 체력 +1, 체력 2 회복. 장비 강화 대상이 아니며 증강 선택 창은 없습니다.

## 재화와 영구 성장

| 표시 | 용도 | 새 회차 |
|---|---|---|
| GOLD | 전투에서 획득, 체력 회복에 사용 | 초기화 |
| SHARDS | 스킬 장비 파괴로 획득, 장비 강화 | 초기화 |
| MEMORY | 방 클리어·정예·보스 보상, 시작 거점 영구 성장 | 보존 |

시작 거점에서 F/B로 영구 체력(+2) 또는 기본 공격력(+1)을 구매합니다. 각각 최대 5단계입니다. ‘첫 장비 강화’는 영구 최대 체력 +1, ‘야수 최초 처치’는 영구 공격력 +1을 해금합니다. 같은 업적은 반복해서 쌓이지 않습니다. 구매와 업적은 종료 후 다시 실행해도 유지됩니다.

저장은 로컬 PlayerPrefs의 `Storyborn.Meta.v03.*` 키를 사용합니다. 현재 도전 중의 장비·방 위치를 이어하는 저장은 없습니다. 이전 v0.2의 사망 횟수만 기록한 데이터는 이 버전의 성장 데이터로 변환하지 않습니다.

## 아트 수정

주인공은 `Assets/Resources/StorybornHero`의 PNG 5개를 사용합니다. 같은 이름·크기의 PNG를 수정해서 덮어쓸 수 있습니다. Import 설정의 **Read/Write Enabled**, Filter Mode Point, Compression None을 유지해 주세요. 런타임이 투명 여백을 제외해 몸 크기를 맞춥니다.

적·나무·풀·출구·활은 `ForestArt.cs`에서 작은 픽셀 텍스처를 생성합니다. 나중에 해당 `Get(kind)` 결과를 실제 스프라이트로 바꿀 수 있습니다. 현재 정예는 난쟁이 그림을 확대해 사용하는 시험형입니다. 정지 포즈 기반 표시이며 완성된 걷기·공격 애니메이션은 아닙니다.

## 구현 범위

이번 목표였던 장비 획득·교체·파괴·강화, 보상 경로 선택, 숲 전투, 야수 보스, 회귀와 영구 성장의 첫 통합 버전입니다. 전체 기획서의 모든 콘텐츠가 완성된 것은 아닙니다.

미구현: 2인조 미니보스 3전투, 앨리스·오즈와 보스 무작위 선택, 나머지 일반 적·정예, 궁극기, 후속 지역, 본편 대사·오인과 정체 공개, 음악·효과음, 정식 도트 애니메이션. 연구소·시작점·아이템 가격·업적 이름은 플레이 시험을 위한 임시 표현입니다.

## 검증

런타임 C#은 Unity API 참조 컴파일로 확인하고, 실제 모델 원본으로 경제·교체·재화 보존·초기화 검사를 실행했습니다. Unity 에디터가 이 환경에 없어 화면·입력·씬·플레이와 플랫폼 빌드는 실제 에디터에서 확인해야 합니다. 상세 결과는 `VALIDATION_KO.md`에 있습니다.
