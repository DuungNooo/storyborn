# STORYBORN v0.4 — 동화의 숲 · 조작과 타격감 개선

**[기존 Unity 프로젝트용 Assets ZIP 다운로드](https://github.com/DuungNooo/storyborn/raw/refs/heads/main/Downloads/Storyborn_v0.4_Assets.zip)**

Unity 종료 → ZIP 해제 → `Assets` 내용물을 기존 프로젝트의 `Assets` 안에 복사·덮어쓰기 → Unity 열기 → **Storyborn → Play Prototype** → Game 뷰 클릭.

최초 연구소 연습 → 시작 거점 → 숲 전투와 보상 경로 → 정예 → 정비 → 야수 보스까지 연결한 통합 프로토타입입니다.

- 좌클릭을 누르고 있으면 3연타, 우클릭 방향 대시. A/D 이동, W/Space 이단 점프·누르는 길이로 높이 조절, S 하강.
- 입력 버퍼, 적 경직·밀림, 짧은 타격 정지, 피해 숫자·파티클·임시 효과음.
- 체력·장비 쿨다운·재화·보스 HUD 개선, 오른쪽 출구 앞에서 F로 직접 경로 선택.
- Q/E 레인보우 장비: 획득 시 직선·화살비·곡사 중 한 스킬 고정.
- 현장 교체·파괴, 남긴 장비 자동 파괴, 파편 강화와 추가 화살.
- 골드·파편·영구 재화 3종. 회귀 시 임시 진행 초기화, 영구 구매·업적 저장.
- F 상호작용, B 강화·영구 성장, Esc 일시정지·효과음 켜기/끄기, 사망 후 R 재시작.
- 수정 가능한 주인공 PNG와 임시 숲·적 픽셀 스프라이트.
